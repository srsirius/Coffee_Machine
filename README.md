# Симулятор кофемашины

Консольное приложение на Python, которое симулирует работу полноценной кофемашины. Программа позволяет пользователю покупать разные виды кофе, пополнять ресурсы машины (воду, молоко, кофейные зерна, одноразовые стаканчики), забирать заработанные деньги и проверять текущее состояние аппарата.

## Возможности

*   **Приготовление кофе:** Эспрессо, латте или капучино. Машина автоматически проверяет наличие достаточного количества ресурсов перед приготовлением.
*   **Пополнение ресурсов:** Последовательное добавление воды, молока, кофейных зерен и одноразовых стаканчиков.
*   **Управление деньгами:** Изъятие всех заработанных от продажи кофе средств.
*   **Проверка состояния:** Просмотр текущих количеств всех ингредиентов и общей суммы денег.
*   **Логика конечного автомата:** Программа использует четкую архитектуру на основе состояний (`MAIN`, `BUY`, `FILL_WATER` и др.) для управления вводом пользователя и потоком выполнения.

## Структура проекта

Вся логика содержится в одном Python-файле (например, `coffee_machine.py`):

*   **`CoffeeMachine` (класс):** Основной класс, инкапсулирующий состояние машины, ресурсы и все обработчики действий.
*   **`State` (вложенный класс):** Определяет строковые константы для состояний машины, что делает переходы между ними читаемыми и предотвращает использование «магических строк».
*   **Управление ресурсами:** 
    *   `_check_resources()`: Проверяет, достаточно ли ингредиентов для выбранного напитка.
    *   `_handle_fill_*()`: Методы для добавления ресурсов.
*   **Обработка ввода:** `process_input()`: Центральный метод, который направляет команды пользователя в зависимости от текущего состояния машины.

## Технологии

*   **Язык:** Python 3.8+
*   **Стандартная библиотека:** Используются только встроенные модули Python (внешние зависимости не требуются).

## Как запустить

1.  Убедитесь, что на вашей системе установлен Python.
2.  Сохраните код в файл с именем `coffee_machine.py`.
3.  Откройте терминал или командную строку.
4.  Перейдите в директорию с файлом.
5.  Запустите скрипт командой:

    ```bash
    python coffee_machine.py
    ```

## Руководство пользователя

После запуска программа будет ждать ваших команд. Доступные действия зависят от текущего состояния кофемашины.

### Главное меню

Когда вы видите приглашение `Write action (buy, fill, take, remaining, exit):`, вы можете ввести одну из следующих команд:

*   `buy` — войти в меню покупки для выбора кофе.
*   `fill` — начать процесс пополнения ресурсов машины.
*   `take` — забрать все заработанные деньги. Машина выведет сумму и обнулит свой баланс.
*   `remaining` — отобразить текущее состояние машины (ингредиенты и деньги).
*   `exit` — выключить программу.

### Покупка кофе

После ввода `buy` машина спросит: `What do you want to buy? 1 - espresso, 2 - latte, 3 - cappuccino, back - to main menu:`

*   Введите `1`, `2` или `3`, чтобы выбрать напиток:
    *   **1 (Эспрессо):** 250 мл воды, 16 г зерен. Стоит $4.
    *   **2 (Латте):** 350 мл воды, 75 мл молока, 20 г зерен. Стоит $7.
    *   **3 (Капучино):** 200 мл воды, 100 мл молока, 12 г зерен. Стоит $6.
*   Введите `back`, чтобы вернуться в главное меню без покупки.

Если машине не хватает какого-либо ингредиента, она выведет сообщение (например, `Sorry, not enough water!`) и вернется в главное меню.

### Пополнение ресурсов

После ввода `fill` машина будет последовательно запрашивать ингредиенты. Вам нужно будет ввести значение для каждого шага:

1.  `Write how many ml of water you want to add:`
2.  `Write how many ml of milk you want to add:`
3.  `Write how many grams of coffee beans you want to add:`
4.  `Write how many disposable cups you want to add:`

После ввода последнего значения машина вернется в главное меню.

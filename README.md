# CoffeeMachine

Простая консольная кофемашина на Python. Реализует покупку напитков, пополнение запасов, выдачу денег и просмотр остатков.

## Возможности

- **Покупка напитков**: эспрессо, латте, капучино (выбор по номеру).
- **Пополнение ресурсов**: вода, молоко, кофейные зёрна, чашки — пошагово.
- **Просмотр состояния**: текущие запасы и выручка.
- **Выдача денег**: снятие всей выручки из машины.
- **Отладка**: информативный `__repr__` для быстрого просмотра состояния объекта.

## Состояния машины

Машина работает в конечных состояниях (FSM):

- `MAIN` — главное меню.
- `BUY` — выбор напитка.
- `FILL_WATER`, `FILL_MILK`, `FILL_BEANS`, `FILL_CUPS` — пошаговый режим пополнения.
- `EXIT` — завершение работы.

## Как запустить

1. Убедитесь, что установлен Python 3.8+.
2. Сохраните код в файл `coffee_machine.py`.
3. Запустите из терминала:

   ```bash
   python coffee_machine.py
Следуйте подсказкам в консоли.
Доступные команды (в состоянии MAIN)
Команда	Описание
buy	Купить напиток (1 — эспрессо, 2 — латте, 3 — капучино)
fill	Пополнить запасы (система запросит каждый ресурс по очереди)
take	Забрать всю выручку из машины
remaining	Показать текущие запасы
exit	Завершить работу
В режиме покупки дополнительно доступна команда back — вернуться в главное меню.

Важные особенности реализации
Проверка ресурсов: перед приготовлением проверяется наличие воды, молока, зёрен и чашек. При нехватке выводится понятное сообщение.
Исправленный _status(): теперь метод только отображает текущие значения и не меняет запасы (в отличие от предыдущих версий, где случайно вызывались методы пополнения).
__repr__: возвращает компактное, но полное представление объекта — удобно при логировании и в тестах.
Пошаговый fill: машина запрашивает каждый ресурс последовательно, чтобы избежать ошибок ввода.
Исправление бага в _status()
Ранее метод _status некорректно вызывал _handle_fill_*, что приводило к незаметному увеличению запасов при каждом запросе остатков. Теперь он просто читает текущие значения атрибутов.

Тестирование
Для быстрой проверки логики можно написать простые тесты, например:

python
def test_buy_espresso():
    m = CoffeeMachine()
    assert m.water == 400
    m.process_input("buy")
    m.process_input("1")
    assert m.water == 150  # 400 - 250
    assert m.money == 554  # 550 + 4
